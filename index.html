Roboball

A UR7e robot arm that juggles a beach ball with a custom paddle end-effector. An Intel RealSense depth camera tracks the ball, a ballistic model predicts where it will fall, and a strike planner moves the paddle there in time.

I worked on trajectory prediction and parts of the planning and control pipeline.

  • ROS 2
  • Python
  • RealSense
  • Inverse kinematics
  • PID control

EmailAgent

A private, fully local email triage and scheduling system. A small open-source LLM only classifies intent; plain Python handles the parts that need to be right — free/busy checks, date math, and state transitions.

Gmail, Google Calendar, and a person-centric CRM in Sheets stay in sync through a scheduling state machine that tracks each back-and-forth.

  • LangGraph
  • Qwen2.5
  • Gmail API
  • Calendar API
  • Pub/Sub

02 — About

How people think, and how to build machines that help.

I'm a senior studying Computer Science and Cognitive Science at UC Berkeley. My work moves between robots, language models, and interfaces, and it usually starts with the same question: what would make this easier for a person to understand?

Lately that has meant teaching a robot arm to juggle, building small local agents that don't hallucinate your calendar, and turning lectures into animations.
